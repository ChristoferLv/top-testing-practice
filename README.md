# Testing Practice

Automated testing practice project developed as part of the JavaScript path of [The Odin Project](https://www.theodinproject.com/paths/full-stack-javascript/courses/javascript), with a focus on **Jest**, **basic TDD**, and validating utility functions.

## Project Objective

The main objective was to practice:
- Writing unit tests with Jest
- The "write tests and make them pass" workflow
- Structuring test cases for common and edge scenarios
- Setting up an ESM environment with Jest using Babel

## What is it?

An assortment of JavaScript functions accompanied by unit tests:
- `capitalize`
- `reverse`
- `calculator` (add, subtract, multiply, divide)
- `caesarCipher`
- `analyzeArray`

## Tested Features

- **Capitalization**: first letter capitalized
- **String reversal**: returns the reversed string
- **Calculator**: basic operations with two numbers
- **Caesar cipher**: character shifting with case preservation and non-alphabetic character support
- **Array analysis**: returns average, minimum, maximum, and length

## How to use

1. Enter the project folder: `Javascript/top-testing-practice`
2. Install the dependencies:
   `npm install`
3. Run the tests:
   `npm test`

## File Structure

- `index.js`: function implementations
- `index.test.js`: Jest test suite
- `babel.config.js`: Babel configuration for Jest compatibility

## Technologies Used

- JavaScript (ES Modules)
- Jest
- Babel (`@babel/preset-env`)
